# Examples

Use the [quickstart](../start/quickstart-worker.md) to scaffold an app with `mantle init` and add a first manifest, [typed queries](../guides/typed-queries.md) for embedding, and [service composition](../cloudflare/service-entry.md) for optional surfaces.

The runnable [reference service](https://github.com/aotter/mantle/tree/v0.2.2-alpha.3/docs/examples/reference-service) exercises the native package integration. See the [generated public website](../../examples/generated-web/README.md) for a native Worker example.
